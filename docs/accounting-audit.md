## 4. เทียบกับโปรแกรม Express

เทียบจากความสามารถที่รู้จักของ Express (ไม่ได้เปิดโปรแกรม Express จริงในเครื่องทดสอบ) จึง**ยืนยันไม่ได้ว่าตรง 100%**
และจากผลด้านล่าง **ยังไม่ตรง 100%**: หลักการลงบัญชีที่ทำแล้วตรงตามหลักบัญชีไทย แต่ขอบเขตเอกสารยังไม่ครบและมีกติกาบางข้อต่างจาก Express

**มีแล้วและลงบัญชีแบบเดียวกับ Express:** ขายเชื่อ/ขายสด/ลดหนี้/เพิ่มหนี้/รับชำระ · ซื้อเชื่อ/ซื้อสด/ลดหนี้/จ่ายชำระ · ภาษีขาย/ซื้อ
(รวมภาษียังไม่ถึงกำหนดของบริการ) · ภ.พ.30 · ภ.ง.ด.3/53 + 50 ทวิ · เช็ครับ/จ่าย (รวมลงวันที่ล่วงหน้า) · กระทบยอดธนาคาร · ถัวเฉลี่ยเคลื่อนที่
· ปรับปรุงสต็อก · ทะเบียนสินทรัพย์ ค่าเสื่อมเส้นตรง จำหน่าย · สมุดรายวัน กลับรายการ ปิดงวด · แยกประเภท งบทดลอง งบการเงิน · ลูกหนี้/เจ้าหนี้รายใบ

**ต่างจาก Express (กติกาที่ระบบตั้งไว้ใน `docs/assumptions.md`):**

| เรื่อง | ระบบนี้ | Express |
|---|---|---|
| ค่าเสื่อมราคา | รายเดือนเต็มเดือน ไม่คิดเดือนที่จำหน่าย (ข้อ 32) | คิดตามจำนวนวัน ถึงวันที่จำหน่าย |
| ขายสินทรัพย์ (บริษัทจด VAT) | ไม่คิดภาษีขาย (ข้อ 32) | ออกใบกำกับภาษี คิด VAT 7% |
| ปิดบัญชีสิ้นปี | **ทำแล้ว** (เฟส 5 โมดูล 1, migration `20261110000105`): CL วันสิ้นปีโอนรายได้/ค่าใช้จ่ายเข้า 3210 ปีใหม่เริ่มจากศูนย์ ต่างที่ครูเปิดคืนแล้วปิดใหม่ = ลง CL ส่วนต่างเพิ่ม (ไม่ลบของเดิม) (assumptions ข้อ 40) | ปิดบัญชีโอนเข้ากำไรสะสม ยกยอดขึ้นปีใหม่ |
| ต้นทุนสินค้า | ถัวเฉลี่ยเคลื่อนที่อย่างเดียว (PLAN เฟส 3 ระบุ FIFO/ถัวเฉลี่ย แต่ยังไม่ได้ทำ FIFO และไม่มีบันทึกการตัดสินใจ) · ลงย้อนวันที่คำนวณใหม่ตามลำดับวันที่แล้ว (ข้อ 6) แต่ปรากฏในสมุดรายวันเป็นคู่ RV/CG | เลือก FIFO/ถัวเฉลี่ย · คำนวณต้นทุนใหม่ตามลำดับวันที่ (แก้รายการเดิมในที่) |

| งบแสดงฐานะการเงิน | **ทำแล้ว**: แยกหมุนเวียน/ไม่หมุนเวียนตามรหัสบัญชี | แยก |

## 6. ต้นทุนถัวเฉลี่ยตามลำดับวันที่ (แบบ Express) — migration `20261110000104`

เจ้าของโปรเจกต์เลือก 10 พ.ย. 2569: คำนวณต้นทุนใหม่ตามลำดับวันที่แบบ Express

- ตัดต้นทุน/ตรวจจำนวนจากยอด **ณ วันที่ของเอกสาร** (รวมรายการวันเดียวกันที่ลงไว้ก่อน) ขาย ตัดสต็อก ส่งคืนผู้ขาย
- ลงรายการที่เคลื่อนไหวสต็อก**ย้อนวันที่** (ซื้อ ขาย รับคืน ส่งคืน ปรับสต็อก) หรือ**ยกเลิก**เอกสาร → คำนวณบัตรสต็อกของสินค้านั้นใหม่ทั้งบัตรตามลำดับวันที่
  - ขาย / ตัดออก = ถัวเฉลี่ย ณ จุดนั้น · รับคืนจากลูกค้า = ต้นทุนต่อหน่วยของใบขายที่อ้าง (ใหม่ล่าสุด) · ซื้อ / ส่งคืนผู้ขาย / รับเข้า = ตามเอกสาร
  - เอกสารที่ยกเลิกแล้วไม่นับ (เหมือนไม่เคยเกิด แบบ Express ลบเอกสาร)
- รายการต้นทุนที่ยอดเปลี่ยน: **กลับรายการเดิม (RV) แล้วลงใหม่ (CG) วันที่เดิม** คำอธิบาย "คำนวณต้นทุนใหม่ CG-0003 (ลงย้อนวันที่ PI-0005)"
  สมุดรายวันและบัตรสต็อกยังแก้ไม่ได้ (กติกา "แก้ย้อนหลังด้วยการกลับรายการเท่านั้น") ค่าใหม่ของบรรทัดบัตรสต็อกเก็บใน `acc.inventory_restatement_lines`
  · การตรวจคำตอบไม่นับคู่ที่กลับ (เหลือ CG ใหม่) · ยกเลิกเอกสารที่เคยคำนวณใหม่ = กลับรายการ CG ปัจจุบัน
- ลงหรือยกเลิกแล้วทำให้สต็อก ณ วันใดติดลบ → ปฏิเสธ บอกสินค้า วันที่ และเอกสารที่ขาด
- บัตรสต็อกแสดงค่าล่าสุด เลขที่อ้างอิงเป็นรายการต้นทุนปัจจุบัน และบอก "คำนวณต้นทุนใหม่"
