## ยังค้าง / ต้องตัดสินใจ

- **มูลค่าการรับคืน/ส่งคืนสินค้า** (บั๊ก 2) ทำตามสเปก "กลับด้าน อ้างเอกสารต้นทาง" ด้วยค่าที่ใช้ในตำราทั่วไป รอยืนยัน (`assumptions.md` ข้อ 37)
- **ห้ามลงวันที่ก่อนความเคลื่อนไหวล่าสุดของสินค้า** (สเปกเฟส 3) ยังไม่บังคับ: ลงย้อนวันที่ได้แต่บัตรสต็อกเรียงตามวันที่ ยอดระหว่างทางอาจติดลบ ทางเลือก: บังคับ (นักเรียนต้องลงตามลำดับวันที่) / เตือน / ปล่อย
- **ลงสมุดรายวันทั่วไปเข้าบัญชีคุมตรง ๆ** (1210 2110 1310 1220 ฯลฯ) ยังทำได้และทำให้ยอดคุมไม่ตรงทะเบียน (ค้างจาก `function-audit.md`) หน้าสินค้าคงเหลือแสดง "ไม่ตรงกัน" ให้เห็นแล้ว ทางเลือก: ปล่อย / เตือน / ห้าม
- **สิทธิ์ตอบ 403 แทน 404** เมื่อนักเรียน/ครูต่างห้องเขียนเข้าบริษัทคนอื่น (อ่านได้ 404 ถูกแล้ว) ข้อมูลไม่รั่ว แต่บอกได้ว่ามีบริษัท id นั้น ความเสี่ยงต่ำ (id เป็น UUID)
- **ปุ่มกลับบนมือถือ** ใช้ `history.length > 1` เปิดลิงก์จากแอปอื่นแล้วกดกลับจะออกไปหน้าก่อนของเบราว์เซอร์ (ไม่ใช่หน้าแรกบริษัท) ปกติของเบราว์เซอร์ ไม่ได้แก้
- หน้าดูสดรายห้องของครู (`/teacher/live/[ห้อง]`) ไม่มีลิงก์ "‹ กลับ" ในหน้า (ใช้เมนูด้านบนแทนได้)
- เว็บจริง: เปิดดูแบบอ่านอย่างเดียวไม่ได้จากเครื่องทดสอบนี้ (proxy) · migration 030–031 **ยังไม่ได้ apply กับ Supabase production**
- อุปกรณ์จริง (`docs/device-test.md`) และ Safari (WebKit รันใน CI)
