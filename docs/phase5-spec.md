ที่มา: `docs/accounting-audit.md` ข้อ 4 · ทำทีละโมดูล หนึ่งโมดูลหนึ่ง PR · กติกาบัญชีที่ตัดสินเองอยู่ใน `docs/assumptions.md` ตั้งแต่ข้อ 40

## 1. ปิดบัญชีสิ้นปี + รอบปีบัญชี (migration `20261110000105`)

**รอบปีบัญชี**
- บริษัทตั้ง "เดือนเริ่มปีบัญชี" ได้ 1–12 (ค่าเริ่มต้น 1 = ปีปฏิทิน) เช่น 4 = 1 เม.ย. – 31 มี.ค.
- เปลี่ยนได้จนกว่าจะเคยปิดบัญชีสิ้นปีครั้งแรก (หลังจากนั้นขอบปีถูกใช้ในบัญชีแล้ว)
- ปีแรกของบริษัทเริ่มที่เดือนที่มีรายการแรก จบที่สิ้นรอบปีนั้น (ปีสั้นได้)
- `acc.fiscal_year_start(บริษัท, วันที่)` = วันแรกของปีบัญชีที่วันนั้นอยู่ ใช้ทุกรายงาน

**ปิดบัญชี** (`acc.close_fiscal_year`, เมนู ปรับปรุง / ปิดงวด → ปิดบัญชีสิ้นปี)
- รายการเลขที่ชุด `CL` ลงวันสิ้นปีบัญชี: เดบิตรายได้ทุกบัญชีที่มียอด เครดิตค่าใช้จ่ายทุกบัญชีที่มียอด ผลต่างเข้า 3210 กำไรสะสม
  (กำไร = เครดิต 3210 · ขาดทุน = เดบิต 3210) ยอดคิดจากทุกรายการถึงวันสิ้นปี (ปีก่อนปิดแล้วจึงเหลือเฉพาะปีนี้)
- ก่อนยืนยันแสดงรายการที่จะลง (preview) ให้นักเรียนตรวจ
- เงื่อนไข: ปีก่อนหน้าที่มีรายการต้องปิดก่อน · งวดก่อนต้นปีนี้ต้องปิดหมดแล้ว · ปีที่ยอดรายได้/ค่าใช้จ่ายเป็นศูนย์ปิดได้โดยไม่มีรายการ CL
- ปิดแล้ว: งวดที่ยังเปิดของปีนั้นปิดให้อัตโนมัติ · ลงรายการใด ๆ ลงวันที่ในปีที่ปิดแล้วไม่ได้ (รวมเดือนที่ยังไม่มีงวด)
- งวดสิ้นปีถูกปิดไปก่อนแล้วก็ปิดบัญชีได้ (ระบบเปิดชั่วคราวในธุรกรรมเดียวเพื่อลง CL แล้วปิดคืน)
- รายการ CL ลงได้จากฟังก์ชันปิดบัญชีเท่านั้น กลับรายการ/แก้จากสมุดรายวันไม่ได้ · 3210 ไม่มีหรือปิดใช้อยู่ = สร้าง/เปิดใช้ให้
- ไม่ปิด 3310 ถอนใช้ส่วนตัว (เป็นบัญชีของกิจการเจ้าของคนเดียว บริษัทจำกัดไม่ใช้) ยกไปตามเดิม
- กันกดซ้ำด้วย idempotency key · ล็อกเดียวกับปิด/เปิดงวด

**เปิดคืน** (ครูประจำห้องเท่านั้น ผ่านปุ่มเปิดงวดคืนเดิม)
- เปิดงวดเดือนใดคืน = การปิดบัญชีของปีที่สิ้นสุดตั้งแต่เดือนนั้นเป็นต้นไปถูกเปิดคืน (`reopened_at`) ลงรายการในปีนั้นได้อีก
- รายการ CL เดิมคงอยู่ (สมุดรายวัน append-only) ปิดบัญชีใหม่ = ลง CL เพิ่มเฉพาะยอดรายได้/ค่าใช้จ่ายที่ยังเหลือ

**รายงาน**
- งบทดลอง: ยอดสะสมเหมือนเดิม แต่**ไม่รวม CL ของปีบัญชีของเดือนที่เลือก** (= งบทดลองก่อนปิดบัญชี)
  เดือนสิ้นปีที่ปิดบัญชีแล้วเลือก "หลังปิดบัญชี" ได้ (รวม CL: เหลือเฉพาะสินทรัพย์ หนี้สิน ทุน)
  ปีใหม่หลังปิดบัญชีจึงไม่มีรายได้/ค่าใช้จ่ายปีก่อน (ยอดอยู่ใน 3210 แล้ว) · ปีก่อนยังไม่ปิด = แสดงคำเตือน
- กระดาษทำการ: ไม่รวม CL ของปีบัญชีนั้น (ช่องงบทดลองเป็นยอดก่อนปิดบัญชี) + คำเตือนเดียวกัน
- งบการเงิน: "ตั้งแต่ต้นปี" = ตั้งแต่ต้นปีบัญชี · ไม่รวม CL ของปีนั้น · ส่วนของเจ้าของแยกบรรทัด
  "กำไร(ขาดทุน)สุทธิปีนี้" กับ "กำไร(ขาดทุน)ปีก่อนที่ยังไม่ได้ปิดบัญชี" (บรรทัดหลังแสดงเมื่อไม่เป็นศูนย์)
- แยกประเภท: แสดงรายการ CL ตามจริง (บัญชีรายได้/ค่าใช้จ่ายปิดเป็นศูนย์ ยอดยกมาปีใหม่ = 0)

**ตาราง** `acc.fiscal_year_closings` (บริษัท ปีเริ่ม ปีสิ้นสุด รายการ CL กำไรสุทธิ ผู้ปิด/เวลา ผู้เปิดคืน/เวลา) RLS อ่านตาม `app.readable_company_ids()`
เขียนผ่านฟังก์ชันเท่านั้น แก้ได้เฉพาะช่องเปิดคืน

**เทสต์** `tests/year-end-closing.test.ts`: สถานการณ์สองปีเทียบเฉลยคิดมือรายบรรทัด (CL ทุกบัญชี งบทดลองก่อน/หลังปิด งบทดลอง/กระดาษทำการ/งบการเงินปีใหม่
ไม่มีรายได้ปีก่อน 3210 = กำไรปีก่อน) · ปีบัญชีเม.ย.–มี.ค. · ขาดทุน · ลงย้อนปีที่ปิดไม่ได้ · ปิดข้ามปีไม่ได้ · CL ลง/กลับเองไม่ได้
· ครูเปิดคืน → ลงเพิ่ม → ปิดใหม่ลง CL เฉพาะส่วนต่าง · เปลี่ยนรอบปีหลังปิดไม่ได้ · นักเรียนอื่นอ่าน/ปิดไม่ได้ · e2e 3 จอ `tests/e2e/year-end.spec.ts`

## 2. งบการเงินแบบหลายขั้น (migration `20261111000106`)

**งบกำไรขาดทุนหลายขั้น** (รูปแบบ TFRS for NPAEs) จัดกลุ่มตามรหัสบัญชี (ผังไทย):
| กลุ่ม | รหัส |
|---|---|
| รายได้จากการขายและการให้บริการ (รับคืน/ส่วนลดจ่ายเป็นรายการหัก) | 41xx, 42xx |
| รายได้อื่น | รายได้รหัสอื่น (43xx ขึ้นไป) |
| ต้นทุนขาย | 51xx |
| ค่าใช้จ่ายในการขายและบริหาร | 52xx (และค่าใช้จ่ายรหัสอื่นที่ไม่เข้ากลุ่มใด) |
| ค่าใช้จ่ายอื่น | 53xx ยกเว้น 531x |
| ต้นทุนทางการเงิน | 531x (ดอกเบี้ยจ่าย) |
| ภาษีเงินได้ | 54xx–59xx |

ขั้น: รายได้สุทธิ − ต้นทุนขาย = กำไรขั้นต้น + รายได้อื่น − ค่าใช้จ่ายในการขายและบริหาร − ค่าใช้จ่ายอื่น
= กำไรก่อนต้นทุนทางการเงินและภาษีเงินได้ − ต้นทุนทางการเงิน = กำไรก่อนภาษี − ภาษีเงินได้ = กำไรสุทธิ (ขั้นที่ยอดเป็นศูนย์ไม่แสดง)

**ต้นทุนขาย** แสดงแบบ สินค้าต้นงวด + ซื้อสุทธิ − สินค้าปลายงวด ได้ทั้งสองระบบ:
- สินค้าต้นงวด/ปลายงวด = ยอด 1310 ณ ต้น/สิ้นงวดที่แสดง
- ซื้อ (5110) ส่วนลดรับ (5120) ส่งคืน (5140) และบัญชี 51xx อื่น (เช่น ค่าขนส่งเข้า) = ยอดจากรายการที่**ไม่ได้**ลงบัญชี 1310
  (รายการรับเข้า/ตัดต้นทุน/ส่งคืนออกจากคลังของระบบต่อเนื่องเป็นการโอนภายใน จึงไม่นับซ้ำ)
- ต้นทุนขาย = ยอดรวมบัญชี 51xx ในงวดเสมอ (ตรงกับบัญชี) ส่วนต่างจากสูตรแสดงเป็น "ปรับปรุงสินค้าอื่น"
  (เช่น รับสินค้ายกมาคู่กับบัญชีทุนระหว่างงวด) ปกติเป็นศูนย์
- ระบบสิ้นงวด: บันทึก "สินค้าคงเหลือปลายงวดตามตรวจนับ" ที่หน้า ปรับปรุง / ปิดงวด → ระบบลง AJ วันสิ้นเดือน
  ปรับ 1310 ให้เท่ายอดตรวจนับ คู่กับ 5130 (`acc.record_ending_inventory`) ใช้ไม่ได้เมื่อบริษัทมีสินค้าที่ติดตามสต็อก (ระบบต่อเนื่องปรับที่หน้าสินค้าคงเหลือ)
  ทำก่อนปิดบัญชีสิ้นปี ยอดปลายปีจึงยกไปเป็นต้นงวดปีใหม่

**งบแสดงฐานะการเงิน** แยกหมุนเวียน/ไม่หมุนเวียนตามรหัส: สินทรัพย์ 11xx–15xx หมุนเวียน 16xx ขึ้นไปไม่หมุนเวียน ·
หนี้สิน 21xx–25xx หมุนเวียน 26xx ขึ้นไปไม่หมุนเวียน · ส่วนของเจ้าของเหมือนเดิม

**เทสต์** `tests/multi-step-statements.test.ts` เทียบเฉลยคิดมือ: ระบบต่อเนื่อง (ซื้อ ขาย ส่งคืน รับเข้าจากทุน) + ตรวจสถานการณ์ของ `accounting-audit` ว่าหลายขั้น = ขั้นเดียว ·
ระบบสิ้นงวด (ซื้อ ส่วนลดรับ ส่งคืน ค่าขนส่งเข้า ตรวจนับปลายเดือน → ยกเป็นต้นงวดเดือนถัดไป → ปิดบัญชีสิ้นปี) · ทุกกลุ่มรายได้/ค่าใช้จ่าย ·
หมุนเวียน/ไม่หมุนเวียน · ต้นทุนขายเท่ายอดบัญชี 51xx เสมอ · e2e 3 จอ

## 3. ยอดยกมาพร้อมรายตัว (migration `20261111000107`)

**ชุดยอดยกมา** หนึ่งชุดต่อบริษัท (`acc.post_opening_balances`) หน้า "ยอดยกมา" ลงครั้งเดียวเป็นรายการ **OB** ณ วันยกมา:
- ยอดบัญชีทั่วไป (นักเรียนพิมพ์เอง: เงินสด ธนาคาร ทุน กำไรสะสม ฯลฯ)
- **ลูกหนี้รายใบ** (ลูกค้า เลขที่ใบเดิม วันที่ ครบกำหนด ยอดค้าง ภาษีขายยังไม่ถึงกำหนดถ้าเป็นบริการ) → Dr 1210 / Cr 2211
- **เจ้าหนี้รายใบ** (ผู้ขาย เลขที่ใบของผู้ขาย วันที่ ยอดค้าง ภาษีซื้อยังไม่ถึงกำหนด) → Cr 2110 / Dr 1411
- **สินทรัพย์ถาวร** พร้อมค่าเสื่อมราคาสะสมยกมา → Dr บัญชีสินทรัพย์ (ราคาทุน) / Cr ค่าเสื่อมราคาสะสม
- **สินค้ายกมา** (สินค้าที่ติดตามสต็อก: จำนวน ต้นทุนต่อหน่วย) → Dr 1310 + บัตรสต็อกรายการ "ยกมา"
- บัญชีคุม (1210 2110 2211 1411 บัญชีของสินทรัพย์ที่ยกมา และ 1310 เมื่อมีสินค้าติดตามสต็อก) มาจากรายตัวเท่านั้น พิมพ์เองไม่ได้ ทะเบียนย่อยจึงเท่ายอดคุมเสมอ
- เดบิตต้องเท่าเครดิต (ข้อความผลต่างเดิมของ post_journal) · วันยกมาต้องก่อนรายการอื่นทุกรายการของบริษัท

**หลังลง** รายตัวใช้งานต่อได้เหมือนเอกสารปกติ:
- ลูกหนี้/เจ้าหนี้ยกมาเป็นใบแจ้งหนี้ที่มีเครื่องหมายยกมา (เลขที่ `OB-0001/<เลขเดิม>` ไม่ใช่ใบกำกับภาษี ไม่อยู่ในรายงานภาษี)
  → รับชำระ/จ่ายชำระ/หัก ณ ที่จ่าย/อายุหนี้ได้ ภาษียังไม่ถึงกำหนดโอนเป็นภาษีขาย/ซื้อเมื่อรับ/จ่ายเงิน
- สินทรัพย์: ค่าเสื่อมสะสมยกมานับเป็นเดือนที่ลงแล้ว ลงค่าเสื่อมเดือนถัดไปต่อจากนั้น · ค่าเสื่อมสะสมยกมาต้องเท่าวิธีเส้นตรงของระบบ ณ วันยกมา (บอกยอดที่ถูก)
- สินค้า: ถัวเฉลี่ยเริ่มจากต้นทุนยกมา

**ยกเลิก** ได้ทั้งชุดเท่านั้น (กลับรายการ OB + ยกเลิกรายตัวทั้งหมด) เมื่อยังไม่มีรับ/จ่ายชำระอ้างใบยกมา ไม่ได้ลงค่าเสื่อม/จำหน่ายสินทรัพย์ยกมา
และสต็อกไม่ติดลบ · ยกเลิกรายใบจากหน้าขาย/ซื้อ/ทะเบียนสินทรัพย์ไม่ได้ · กลับรายการ OB จากสมุดรายวันไม่ได้

**เทสต์** `tests/opening-balances.test.ts` เทียบเฉลยคิดมือ: OB ทุกบรรทัด · รับชำระใบยกมา (ภาษีโอน 2211→2210) · จ่ายชำระพร้อมหัก ณ ที่จ่าย ·
ค่าเสื่อมเดือนแรกต่อจากยอดยกมา · ขายสินค้ายกมา (ต้นทุนถัวเฉลี่ย) · อายุหนี้ · ทะเบียนย่อย = ยอดคุม · กรณีผิด (ไม่ดุล พิมพ์บัญชีคุม
ค่าเสื่อมสะสมไม่ตรง มีรายการก่อนวันยกมา ซ้ำ) · ยกเลิกทั้งชุด/ยกเลิกไม่ได้ · ยกเลิกรายใบไม่ได้ · e2e 3 จอ

## 4. เอกสารขาย: ใบเสนอราคา → ใบสั่งขาย → ขายเชื่อ → ใบวางบิล · รับเงินมัดจำ (migration `20261111000108`)

**ใบเสนอราคา (QT) / ใบสั่งขาย (SO)** ไม่ลงบัญชี (`acc.sales_orders` + บรรทัด) ลูกค้า วันที่ ยืนราคาถึง/กำหนดส่ง แบบราคา ส่วนลด ยอดคิดสูตรเดียวกับใบขาย
- ใบสั่งขายสร้างจากใบเสนอราคาได้ (คัดลอกรายการ อ้างกลับ) ใบเสนอราคาที่มีใบสั่งขายอ้าง = "อนุมัติแล้ว"
- ขายเชื่อจากใบสั่งขาย: ดึงรายการที่ยังไม่ส่ง ส่งบางส่วนได้ จำนวนที่ส่งรวมไม่เกินที่สั่ง (`acc.sales_order_deliveries`) ส่งครบ = ปิด
- แก้ไม่ได้ ยกเลิกได้ (ใบสั่งขายยกเลิกไม่ได้เมื่อมีใบขาย/เงินมัดจำอ้างที่ยังไม่ยกเลิก)

**รับเงินมัดจำ (DP)** ลงบัญชี: Dr เงินสด/เงินฝาก / Cr 2420 เงินมัดจำรับ (ฐาน) / Cr 2210 ภาษีขาย
- ภาษีถึงกำหนดเมื่อรับเงินก่อนส่งมอบ (ประมวลรัษฎากร ม.78(1)(ก) สินค้า · ม.78/1(1) บริการ) จึงออกใบกำกับภาษีตอนรับมัดจำทั้งสินค้าและบริการ
- อ้างใบสั่งขายได้ (ไม่บังคับ)
**หักเงินมัดจำตอนขาย** (ระบุในใบขายเชื่อ): เอกสาร DA ลงวันที่ใบขาย Dr 2420 (ฐานส่วนที่หัก) / Dr ภาษี (ส่วนที่หัก) / Cr 1210
- สินค้า: ภาษีส่วนที่หักลดภาษีขาย 2210 (ภาษีของใบขาย = เต็มจำนวน − ที่เสียไปตอนรับมัดจำ) และแสดงเป็นรายการลบในรายงานภาษีขาย
- บริการ: ภาษีส่วนที่หักลดภาษีขายยังไม่ถึงกำหนด 2211 ของใบนั้น (เสียไปแล้วตอนรับมัดจำ) ไม่อยู่ในรายงานภาษี
- หักบางส่วนได้ ภาษีตามสัดส่วน (ครั้งสุดท้ายรับเศษที่เหลือ) ยอดค้างของใบขายลดตามที่หัก
- ยกเลิกใบหักมัดจำได้ (กลับรายการ) · ยกเลิกเงินมัดจำไม่ได้เมื่อมีการหักอ้างอยู่ · ยกเลิกใบขายไม่ได้เมื่อมีการหักมัดจำอ้างอยู่

**ใบวางบิล (BL)** ไม่ลงบัญชี รวมใบขายเชื่อ/ใบเพิ่มหนี้ที่ค้างของลูกค้าหนึ่งราย ยอดตามยอดค้าง ณ วันวางบิล กำหนดชำระ
- ใบหนึ่งอยู่ในใบวางบิลที่ยังไม่ยกเลิกได้ใบเดียว · สถานะ "ชำระครบ" เมื่อทุกใบในบิลไม่มียอดค้าง · ยกเลิกได้ · พิมพ์ได้

**เทสต์** `tests/sales-documents-flow.test.ts` เทียบเฉลยคิดมือ: QT → SO → ขายเชื่อบางส่วน/ครบ · มัดจำสินค้า (ภาษีขายเดือนรับมัดจำ + เดือนขายสุทธิ = ภาษีเต็ม)
· มัดจำบริการ (2211 ลด) · หักบางส่วน 2 ครั้ง ภาษีรวมพอดี · รายงานภาษีขาย = ยอด 2210 · ใบวางบิล + รับชำระ → ชำระครบ · ยกเลิกตามกติกา · e2e 3 จอ

## 5. เอกสารซื้อ: ใบสั่งซื้อ → ใบรับสินค้า → บันทึกซื้อ · ใบเพิ่มหนี้จากผู้ขาย · จ่ายเงินมัดจำ (migration `20261111000109`)

**ใบสั่งซื้อ (PO)** ไม่ลงบัญชี (`acc.purchase_orders` + บรรทัด) ผู้ขาย วันที่ กำหนดส่ง แบบราคา (ผู้ขายไม่จด VAT = ไม่มีภาษี) ส่วนลด
- ใบรับสินค้า/ซื้อเชื่อ/ซื้อสดอ้างใบสั่งซื้อได้ รับบางส่วนได้ จำนวนที่รับรวมไม่เกินที่สั่ง (`acc.purchase_order_receipts`) รับครบ = ปิด
- แก้ไม่ได้ ยกเลิกได้เมื่อไม่มีเอกสารอ้างที่ยังไม่ยกเลิก

**ใบรับสินค้า (GR)** ของมาถึงก่อนใบกำกับภาษี (มีแต่ใบส่งของ) ลงบัญชีตามราคาก่อนภาษีในใบส่งของ:
Dr บัญชีซื้อของสินค้า (5110) / Cr 2130 สินค้ารับแล้วยังไม่ได้รับใบแจ้งหนี้ · สินค้าติดตามสต็อกรับเข้าคลังทันที (IM เหมือนบันทึกซื้อ)
- เฉพาะสินค้า (ไม่ใช่บริการ) ต้องเลือกสินค้าทุกบรรทัด ไม่มีภาษี (ยังไม่มีใบกำกับ) ไม่เป็นเจ้าหนี้ (ไม่อยู่ในเจ้าหนี้คงค้าง จ่ายชำระไม่ได้)
- **บันทึกซื้อเชื่อจากใบรับสินค้า**: เลือกบรรทัดของใบรับสินค้าที่ยังไม่ได้รับใบแจ้งหนี้ จำนวนรวมไม่เกินที่รับ (`acc.purchase_receipt_matches`)
  ใบซื้อลงตามปกติ (Dr 5110 / Dr ภาษีซื้อ / Cr 2110) แล้วลงรายการล้าง GM: Dr 2130 (มูลค่าตามใบรับสินค้าของส่วนที่จับคู่) / Cr 5110
  บรรทัดที่จับคู่ไม่รับเข้าคลังซ้ำ ราคาในใบกำกับต่างจากใบส่งของ = ส่วนต่างค้างใน 5110 (เข้าต้นทุนขาย)
- ยกเลิกใบรับสินค้าไม่ได้เมื่อมีใบซื้ออ้างที่ยังไม่ยกเลิก · ยกเลิกใบซื้อ = กลับ GM ด้วย ใบรับสินค้ากลับมาค้างรับใบแจ้งหนี้

**ใบเพิ่มหนี้จากผู้ขาย (PD)** อ้างใบซื้อเชื่อ (เลขที่ใบเพิ่มหนี้ของผู้ขาย + เหตุผล) Dr บัญชีของรายการ (สินค้า 5110 / บริการ บัญชีบรรทัดแรกของใบเดิม)
/ Dr ภาษีซื้อ (สินค้า 1410 · บริการ 1411 ถึงกำหนดตอนจ่าย) / Cr 2110 · เป็นเจ้าหนี้แยกใบ จ่ายชำระได้ อยู่ในเจ้าหนี้คงค้าง · ไม่เปลี่ยนจำนวนในคลัง

**จ่ายเงินมัดจำ (VD)** เลขที่ใบกำกับภาษี/ใบรับเงินมัดจำของผู้ขาย: Dr 1520 เงินมัดจำจ่าย (ฐาน) / Dr 1410 ภาษีซื้อ / Cr เงินสด/เงินฝาก
- ผู้ขายจด VAT ต้องออกใบกำกับตอนรับมัดจำ (ม.78(1)(ก), ม.78/1(1)) จึงขอคืนภาษีซื้อในเดือนที่จ่ายทั้งสินค้าและบริการ
  บริษัทไม่จด VAT = ภาษีรวมในเงินมัดจำ · อ้างใบสั่งซื้อได้ (ไม่บังคับ)
**หักเงินมัดจำตอนบันทึกซื้อเชื่อ** เอกสาร VA ลงวันที่ใบซื้อ: Dr 2110 / Cr 1520 (ฐานส่วนที่หัก) / Cr ภาษีซื้อส่วนที่หัก
- สินค้า: ลด 1410 และเป็นรายการลบในรายงานภาษีซื้อ (ภาษีส่วนนี้ขอคืนไปแล้วตอนจ่ายมัดจำ) · บริการ: ลด 1411 ของใบนั้น
- ภาษีตามสัดส่วน ครั้งสุดท้ายรับเศษ · ยอดค้างของใบซื้อลดตามที่หัก · ยกเลิกตามกติกาเดียวกับฝั่งขาย

**เทสต์** `tests/purchase-documents-flow.test.ts` เทียบเฉลยคิดมือ: PO → GR บางส่วน (สต็อก + 2130) → ซื้อเชื่อจาก GR ราคาต่าง (GM, 5110 ส่วนต่าง)
· มัดจำสินค้า/บริการ + หักตอนซื้อ · ใบเพิ่มหนี้ + จ่ายชำระ · รายงานภาษีซื้อ = ยอด 1410 · ยกเลิกตามกติกา · e2e 3 จอ

## 6. ส่วนลดเงินสดตอนรับ/จ่ายชำระ (migration `20261111000110`)

ใส่ส่วนลดเงินสดรายใบในใบเสร็จรับชำระ/ใบสำคัญจ่าย (ไม่บังคับ): **ยอดตัดหนี้ = เงินที่รับ/จ่าย + ส่วนลด** ไม่เกินยอดค้าง
- รับชำระ: Dr เงิน (สุทธิหลังหัก ณ ที่จ่าย) Dr 1420 Dr 4210 ส่วนลดจ่าย / Cr 1210 ยอดตัดหนี้
- จ่ายชำระ: Dr 2110 ยอดตัดหนี้ / Cr เงิน Cr 2230 Cr 5120 ส่วนลดรับ
- **สินค้า**: ภาษีขาย/ซื้อลงไปแล้วตอนออกใบกำกับ ส่วนลดเงินสดไม่ลดภาษี (ลดภาษีต้องออกใบลดหนี้ ม.82/10) ส่วนลดทั้งจำนวนลง 4210/5120
- **บริการ**: ภาษียังไม่ถึงกำหนด (2211/1411) ของยอดที่ตัด แบ่งตามสัดส่วน ส่วนที่รับ/จ่ายเงินถึงกำหนด (→ 2210/1410)
  ส่วนของส่วนลดไม่มีการรับ/จ่ายเงินจึงไม่ถึงกำหนด ล้างออก: ส่วนลดลง 4210/5120 เฉพาะฐานก่อนภาษี
  ภาษีในรายงาน = ภาษีของเงินที่รับ/จ่ายจริง
- หัก ณ ที่จ่ายคิดจากเงินที่จ่ายจริง (ไม่รวมส่วนลด) · จ่ายเป็นเช็ค: ยอดเช็ค = เงินที่จ่ายจริง
- เก็บใน `allocations` / `purchase_allocations`: amount = ยอดตัดหนี้ · discount · discount_vat (ภาษีที่ล้างพร้อมส่วนลด)
  ใบเสร็จ/ใบสำคัญจ่าย: gross = ยอดตัดหนี้ discount = ส่วนลด total = เงิน

## 7. ต้นทุนสินค้าแบบเข้าก่อนออกก่อน (FIFO) (migration `20261111000111`)

**เลือกวิธี** ระดับบริษัท (หน้าสินค้าคงเหลือ ตั้งต้นถัวเฉลี่ย) และรายสินค้า (หน้าสินค้า / บริการ ว่าง = ตามบริษัท)
- เปลี่ยนวิธีของสินค้าได้จนกว่าจะมีความเคลื่อนไหวในบัตรสต็อก · วิธีของบริษัทเปลี่ยนได้จนกว่าสินค้าที่ใช้วิธีของบริษัทจะเคลื่อนไหว

**FIFO** เดินบัตรสต็อกตามลำดับวันที่ (ลำดับเดียวกับการคำนวณใหม่ของ migration 104) เก็บชั้นต้นทุน (จำนวน มูลค่า วันที่รับ)
- รับเข้า (ซื้อ ใบรับสินค้า ยกมา ปรับสต็อกเข้า) = ชั้นใหม่ตามมูลค่าเอกสาร · รับคืนจากลูกค้า = ชั้นใหม่ตามต้นทุนต่อหน่วยของใบขายที่อ้าง
- ขาย / ปรับสต็อกตัดออก = ตัดจากชั้นเก่าสุด ชั้นที่ตัดบางส่วนคิดมูลค่าตามสัดส่วน (ปัดสตางค์) ตัดหมดทั้งสต็อก = มูลค่าที่เหลือทั้งหมด
- ส่งคืนผู้ขาย = มูลค่าตามใบลดหนี้ (เหมือนถัวเฉลี่ย) ตัดจำนวนจากชั้นเก่าสุด ส่วนต่างระหว่างมูลค่าชั้นที่ตัดกับมูลค่าเอกสารปรับเข้าชั้นเก่าสุดที่เหลือ
- ลงย้อนวันที่ / ยกเลิก: คำนวณ FIFO ใหม่ทั้งบัตร รายการต้นทุนที่ยอดเปลี่ยนกลับรายการ (RV) แล้วลงใหม่ (CG) แบบเดิม
- บัตรสต็อกแสดงชั้นต้นทุนคงเหลือ (ขายครั้งต่อไปตัดชั้นไหน) · ผลรวมชั้น = มูลค่าคงเหลือ = บัญชี 1310

**เทสต์** `tests/fifo-costing.test.ts` เฉลยคิดมือ: ซื้อ 2 ราคา ขาย ตรวจนับขาด ลงซื้อย้อนวันที่ (คิดใหม่ 2 รายการ) รับคืน ส่งคืน ขาย ยกเลิก
· สุ่ม 80 เอกสารเทียบโมเดล FIFO ที่คิดแยก (`tests/accounting-audit.test.ts`) · e2e `tests/e2e/fifo.spec.ts` 3 จอ

## 8. หลายคลัง + โอนย้ายระหว่างคลัง (migration `20261111000112`)

**คลัง** (`acc.warehouses`) รหัส ชื่อ เปิด/ปิดใช้ · ทุกบริษัทมีคลังหลัก MAIN (สร้างเมื่อใช้ครั้งแรก ปิดใช้ไม่ได้)
- ปิดคลังได้เมื่อไม่มีสินค้าคงเหลือในคลังนั้น · เอกสารเลือกคลังที่ปิดแล้วไม่ได้
**จำนวนแยกคลัง ต้นทุนรวมทั้งบริษัท**: บรรทัดบัตรสต็อกมีคลัง ต้นทุนต่อหน่วย (ถัวเฉลี่ย/FIFO) คิดรวมทุกคลังของสินค้านั้นเหมือนเดิม
- ใบขาย/ขายสด ใบซื้อ/ซื้อสด ใบรับสินค้า ปรับสต็อก เลือกคลังได้ (ไม่เลือก = คลังหลัก) ใบลด/เพิ่มหนี้ = คลังของใบที่อ้าง ยกเลิก = คลังเดิม
- คงเหลือรายคลัง ณ สิ้นวันใด ๆ ต้องไม่ติดลบ (ตรวจตอนบันทึก/ยกเลิกทุกเอกสาร)
**โอนย้าย (TR)** คลังต้นทาง → ปลายทาง หลายสินค้า **ไม่ลงบัญชี** (ยังอยู่ใน 1310 มูลค่าเท่าเดิม) ยกเลิกได้ถ้าไม่ทำให้คลังใดติดลบ

**เทสต์** `tests/warehouses.test.ts` เฉลยคิดมือ: ซื้อเข้า 2 คลัง ขายเกินของในคลังไม่ได้ ต้นทุนเฉลี่ยรวม โอนไม่ลงบัญชี
รับคืนเข้าคลังของใบขาย ยกเลิกโอนที่ทำให้ติดลบไม่ได้ ปิดคลัง · e2e `tests/e2e/warehouses.spec.ts` 3 จอ

## 9. เงินสดย่อย + ฝาก/ถอน/โอนเงินระหว่างบัญชี (migration `20261111000113`)

**ย้ายเงิน (BT)** หน้าเงินสด/ธนาคาร → ฝาก / ถอน / โอนเงิน: จากบัญชี 11xx ไปบัญชี 11xx อื่น (ไม่รวม 1140)
- ลงบัญชี เดบิต บัญชีปลายทาง (จำนวนเงิน) · เดบิต ค่าธรรมเนียม (ถ้ามี ตั้งต้น 5260) / เครดิต บัญชีต้นทาง (จำนวนเงิน + ค่าธรรมเนียม)
- ชื่อรายการ: ต้นทาง 1110 = ฝากเงิน · ปลายทาง 1110 = ถอนเงิน · อื่น ๆ = โอนเงิน · ยกเลิกได้ด้วยการกลับรายการ (RV) ต้องมีเหตุผล

**เงินสดย่อยระบบวงเงินคงที่ (imprest)** หน้าเงินสด/ธนาคาร → เงินสดย่อย
- ตั้ง/ปรับวงเงิน (PC): ปรับยอดบัญชี 1140 ให้เท่าวงเงินใหม่คู่กับบัญชีเงินสด/ธนาคาร พร้อมชื่อผู้รักษา ลดได้ไม่ต่ำกว่าใบสำคัญที่รอเบิก
- ใบสำคัญจ่ายเงินสดย่อย (PCV): วันที่ จ่ายให้ รายการ บัญชีค่าใช้จ่าย จำนวนเงิน เลขที่ใบเสร็จ **ไม่ลงบัญชี**
  จ่ายได้ไม่เกินเงินคงเหลือในมือ (= วงเงิน − ใบสำคัญที่รอเบิก) · ยกเลิกได้ถ้ายังไม่เบิกชดเชย
- เบิกชดเชย (PC): เลือกใบสำคัญที่รอเบิก ลงบัญชี เดบิต ค่าใช้จ่ายรวมตามบัญชีของใบ / เครดิต บัญชีที่จ่าย · 1140 คงเท่าวงเงิน
