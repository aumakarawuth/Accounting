# เฟส 3: สินทรัพย์ดำเนินงาน

เอกสารนี้เริ่มขอบเขตการพัฒนาหลังจากเอกสารขาย ซื้อ ภาษี และสมุดบัญชีในเฟส 2
เสร็จแล้ว โดยทุกเหตุการณ์ที่มีผลต่อบัญชีต้องลงผ่าน `acc.post_journal` และแก้ไข
ย้อนหลังด้วยเอกสารกลับรายการเท่านั้น

## ลำดับงาน

1. **สินค้าคงเหลือและต้นทุนขาย** — ฐานข้อมูลการเคลื่อนไหวสินค้า, ยอดคงเหลือ,
   ต้นทุนถัวเฉลี่ยเคลื่อนที่, ปรับปรุง/ตรวจนับ, และการลง 1310/5110 เมื่อซื้อหรือขายสินค้า
2. **กระทบยอดธนาคาร** — รายการเดินบัญชี, การจับคู่กับเงินรับ/เงินจ่าย, ยอดต่างและรายงาน
3. **เช็ครับและเช็คจ่าย** (ทำแล้ว · migration 026) — ออก เช็คผ่านธนาคาร คืนเช็ค และสถานะก่อนถึงกำหนด
4. **สินทรัพย์ถาวร** (ทำแล้ว · migration 027) — ทะเบียนสินทรัพย์, ค่าเสื่อมราคา, จำหน่าย และสมุดรายวันอัตโนมัติ

## สินค้าคงเหลือ: ข้อตกลงทางบัญชี

- ใช้ **perpetual inventory** และ **ต้นทุนถัวเฉลี่ยเคลื่อนที่** แยกตามบริษัทและสินค้า
- เฉพาะ `items.is_service = false` เท่านั้นที่เคลื่อนไหวสต็อก; บริการไม่มีจำนวนหรือ COGS
- รับสินค้าจากใบซื้อเพิ่มจำนวนและมูลค่าที่รับจริง (ไม่รวม VAT ที่ขอคืนได้)
- ขายสินค้าลดจำนวนตามต้นทุนเฉลี่ย ณ เวลาลงเอกสาร และลง เดบิต 5110 ต้นทุนขาย /
  เครดิต 1310 สินค้าคงเหลือ ในรายการเดียวกับเอกสารขาย
- ใบลดหนี้ซื้อ, ใบลดหนี้ขาย, ยกเลิกเอกสาร และการปรับปรุงสต็อกสร้าง movement กลับด้าน
  โดยอ้างถึงเอกสารต้นทาง จึงตรวจสอบย้อนกลับได้
- ไม่อนุญาตให้ยอดติดลบ และไม่อนุญาตให้ลงวันที่ก่อน movement ล่าสุดของสินค้านั้น เพื่อไม่ให้
  ต้นทุนถัวเฉลี่ยของเอกสารที่ออกแล้วเปลี่ยนย้อนหลัง
- เปิดยอดครั้งแรกและผลต่างจากตรวจนับใช้เอกสารปรับสต็อก พร้อมบัญชีคู่ตรงข้ามที่ผู้ใช้เลือก
  (ค่าเริ่มต้น: 5210 ผลต่างจากสต็อก)

## เกณฑ์รับงานส่วนสินค้าคงเหลือ

- ตาราง movement เขียนตรง แก้ หรือลบไม่ได้; แยกสิทธิ์ด้วย RLS และล็อกเมื่อส่งงาน
- ทุก movement มีจำนวนก่อน/หลัง ต้นทุนต่อหน่วย มูลค่า และเอกสารอ้างอิง
- ทดสอบรับเข้า ขาย คืนสินค้า ปรับปรุง ยกเลิก การแข่งกันบันทึก และการแยกบริษัท
- รายงาน stock card และมูลค่าสินค้าคงเหลือตรงกับบัญชี 1310 ทุกครั้ง

## เช็ครับ / เช็คจ่าย: ข้อตกลงทางบัญชี (ข้อ 3)

ตาราง `acc.cheques` (ทะเบียน แก้ไม่ได้) + `acc.cheque_events` (เหตุการณ์ เพิ่มได้อย่างเดียว สถานะ = เหตุการณ์ล่าสุด)
เขียนได้ผ่าน `acc.register_cheque` / `acc.cheque_action` เท่านั้น เลขที่รายการบัญชีชุด `CQ`

| เหตุการณ์ | เช็ครับ | เช็คจ่าย |
|---|---|---|
| รับ/จ่ายเช็ค | Dr 1220 เช็ครับ (หน้าเช็คหลังวันรับ = 1221 เช็ครับลงวันที่ล่วงหน้า) / Cr บัญชีคู่ | Dr บัญชีคู่ / Cr 2120 เช็คจ่าย (ล่วงหน้า = 2121) |
| ผูกเอกสาร | ใบเสร็จรับชำระ (RE) ใช้บัญชีพักเช็คเป็นบัญชีรับเงิน ตัดลูกหนี้รายใบตามเดิม | จ่ายชำระ (PV) ใช้ 2120/2121 เป็นบัญชีจ่ายเงิน หัก ณ ที่จ่าย/50 ทวิ ตามเดิม |
| สถานะเริ่ม | รอนำฝาก | รอเรียกเก็บ |
| นำฝาก | ไม่ลงบัญชี บันทึกบัญชีเงินฝาก (11xx ที่ไม่ใช่เงินสด) → รอเรียกเก็บ | — |
| เช็คผ่าน | Dr เงินฝากที่นำเข้า / Cr บัญชีพักเช็ค | Dr บัญชีพักเช็ค / Cr เงินฝากที่สั่งจ่าย |
| เช็คคืน / ยกเลิก | กลับรายการตอนรับเช็ค (`reverse_journal`) · ผูกใบเสร็จ = ยกเลิกใบเสร็จ (`void_document`) ยอดค้างกลับมา | กลับรายการตอนจ่ายเช็ค · ผูกใบสำคัญจ่าย = ยกเลิก (`void_purchase_document`) |

- ลำดับสถานะ: เช็ครับ รอนำฝาก → รอเรียกเก็บ → ผ่าน/คืน · รอนำฝาก → ยกเลิก · เช็คจ่าย รอเรียกเก็บ → ผ่าน/คืน/ยกเลิก (ผ่าน/คืน/ยกเลิกแล้วเปลี่ยนต่อไม่ได้)
- นำฝากและเช็คผ่านลงวันที่ก่อนวันที่หน้าเช็คไม่ได้ ทุกเหตุการณ์ลงวันที่ก่อนวันรับ/จ่าย (หรือวันนำฝาก) ไม่ได้
- เช็คลงวันที่ล่วงหน้าที่ถึงกำหนดแล้วยังอยู่ใน 1221/2121 จนผ่าน (ไม่โอนเข้า 1220/2120 เมื่อถึงวันหน้าเช็ค)
- บัญชีพักเช็คใช้เป็นบัญชีรับ/จ่ายเงินของใบเสร็จ/จ่ายชำระได้เฉพาะเมื่อเรียกจาก `register_cheque` และยกเลิกใบนั้นจากฝั่งขาย/ซื้อตรง ๆ ไม่ได้ (ต้องทำที่ทะเบียนเช็ค) ยอดบัญชีพักเช็คจึงเท่ากับเช็คที่ค้างในทะเบียนเสมอ
- เลขที่เช็ค + ธนาคาร ลงซ้ำไม่ได้ เว้นแต่ฉบับเดิมยกเลิกแล้ว

## สินทรัพย์ถาวร: ข้อตกลงทางบัญชี (ข้อ 4)

ตาราง `acc.fixed_assets`, `acc.depreciation_runs`, `acc.depreciation_lines`, `acc.asset_disposals` แก้ไม่ได้
(ยกเว้นบันทึกการยกเลิก/กลับรายการครั้งเดียว) เขียนผ่านฟังก์ชันเท่านั้น

- **ทะเบียน**: รหัส ชื่อ วันที่ได้มา ราคาทุน ราคาซาก อายุ (เดือน) บัญชีสินทรัพย์ (16xx) ค่าเสื่อมสะสม (16xx อีกบัญชี) ค่าเสื่อมราคา (ค่าใช้จ่าย ตั้งต้น 5250)
  บันทึกการได้มาจากหน้านี้ได้ (`FA` Dr สินทรัพย์ / Cr บัญชีคู่) หรือไม่ลงถ้าซื้อผ่านหน้าบันทึกซื้อแล้ว
- **ค่าเสื่อมเส้นตรงรายเดือน**: ต่อเดือน = ปัดครึ่งขึ้น((ราคาทุน − ราคาซาก) / อายุ, 2 ตำแหน่ง) ยอดสะสมไม่เกินมูลค่าเสื่อม เดือนสุดท้ายรับส่วนต่างให้ครบพอดี
  (`app.depreciation_cum` = `apps/web/lib/depreciation.ts` มีเทสต์เทียบ 5,000 ชุด)
- **เริ่มคิด** เดือนที่ได้มาเต็มเดือน (เลือกเดือนถัดไปได้) **ไม่คิดเดือนที่จำหน่าย**
- **ลงค่าเสื่อมประจำเดือน** (`acc.post_depreciation`): รายการปรับปรุง `AJ` วันสิ้นเดือน (เข้าช่องปรับปรุงของกระดาษทำการ) Dr ค่าเสื่อมราคา / Cr ค่าเสื่อมราคาสะสม แยกบรรทัดตามสินทรัพย์
  เดือนที่ยังไม่ได้ลง (เช่น ลงทะเบียนย้อนหลัง) ลงรวมในรอบนี้โดยเก็บเดือนของค่าเสื่อมแต่ละบรรทัดไว้ในทะเบียน
- **กลับรายการค่าเสื่อม**: เฉพาะรอบที่เป็นเดือนล่าสุดของทุกสินทรัพย์ในรอบนั้นและสินทรัพย์ยังไม่จำหน่าย (RV วันสิ้นเดือนเดิม) แล้วลงใหม่ได้
- **จำหน่าย/ขาย** (`FD`): ต้องลงค่าเสื่อมถึงเดือนก่อนเดือนที่จำหน่ายพอดี Dr ค่าเสื่อมสะสม + บัญชีรับเงิน (+ 5320 ขาดทุน) / Cr ราคาทุน (+ 4330 กำไร)
  ราคาขายเป็น 0 = ตัดจำหน่าย ยังไม่คิดภาษีขายจากการขายสินทรัพย์ (ถ้าต้องออกใบกำกับภาษีให้ใช้เอกสารขาย) กลับรายการจำหน่ายได้
- **ยกเลิกทะเบียน**: ได้เมื่อยังไม่ลงค่าเสื่อมและไม่จำหน่าย (กลับรายการ FA ถ้ามี) รหัสเดิมใช้ใหม่ได้
- **รายงานทะเบียน ณ สิ้นเดือน** (`acc.fixed_asset_register`): ราคาทุน ค่าเสื่อม/เดือน ค่าเสื่อมเดือนนี้ ค่าเสื่อมสะสม มูลค่าตามบัญชี สถานะ (ใช้งาน/คิดครบ/จำหน่ายแล้ว)
