## สิ่งที่พบและแก้แล้ว

1. **เมนู "รายงาน" และ "งานของฉัน" เปิดแล้วไม่พบหน้า (404)** ทั้งแถบข้างและแถบล่างมือถือ → สร้างหน้าแล้ว
   - รายงาน: รวมลิงก์รายงานทุกตัว (แยกประเภท งบทดลอง กระดาษทำการ งบการเงิน ลูกหนี้ เจ้าหนี้ ภ.พ.30 หัก ณ ที่จ่าย)
   - งานของฉัน: สถานะการส่งงาน (โหมดส่งงาน) และรายการที่ครูคอมเมนต์
2. **หน้าผู้ดูแลระบบบนมือถือ**: ช่องเลือกครูประจำห้องตัวอักษรเล็กกว่า 16px (iPhone ซูมหน้าเองเมื่อแตะ) → แก้แล้ว
3. **เปิดกระดาษทำการแบบที่ถูกปิด** (เช่น ลิงก์เก่า `?format=6`) เคยขึ้นหน้าผิดพลาด → แสดงข้อความแจ้งและแบบที่เปิดอยู่แทน

## รอเจ้าของโปรเจกต์ตัดสินใจ

- **ลงสมุดรายวันทั่วไปเข้าบัญชีคุมได้ตรง ๆ** (ลูกหนี้ 1210 เจ้าหนี้ 2110 ภาษีขาย/ซื้อ) บน Supabase มี JV-0001 (ทดสอบตั้งแต่เฟส 1)
  เครดิตเจ้าหนี้การค้า 500 โดยไม่มีใบซื้อ ยอดคุมเจ้าหนี้จึงไม่ตรงกับรายตัวเจ้าหนี้ (บัญชีคู่ยังดุล) ทางเลือก: ปล่อยไว้ (สอนการลงบัญชีด้วยมือ) /
  เตือนเมื่อลงบัญชีคุม / ห้ามลงบัญชีคุมจากสมุดรายวันทั่วไป
