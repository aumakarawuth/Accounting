# ทดสอบกับผู้ใช้จริง 5–10 คน (เฟส 4)

PLAN.md ข้อ 12 กำหนดให้ทดสอบกับผู้ใช้จริงก่อน go-live เจ้าของโปรเจกต์เป็นผู้จัดและสังเกตเอง เอกสารนี้คือแบบฟอร์มและสคริปต์ที่ใช้

## เตรียมก่อนวันทดสอบ

- [ ] เว็บช่วงพัฒนา (Vercel + Supabase) apply migration ล่าสุดแล้ว `/api/health` ตอบ `{"ok":true}`
- [ ] ห้องทดสอบ 1 ห้อง ครู 1–2 คน นักเรียน 5–8 คน (รหัสผ่านชั่วคราวพิมพ์จากหน้าห้องเรียน ไม่ใช้รหัสจริงของนักเรียน)
- [ ] ชุดโจทย์ตัวอย่าง 5 ข้อ (ใช้ "ชุดโจทย์ตัวอย่าง" ข้างล่าง) มอบหมายเป็น "ส่งงาน" 1 งาน และ "สอบ 15 นาที" 1 งาน
- [ ] อุปกรณ์จริง: iPhone (Safari) ≥ 2 เครื่อง, Android (Chrome) ≥ 2 เครื่อง, iPad 1 เครื่อง, คอมห้องเรียน 1 เครื่อง + โปรเจกเตอร์ (โหมดสาธิต)
- [ ] ผู้สังเกต 1 คนต่อผู้ทดสอบ 2–3 คน จดตามแบบฟอร์มข้อ 3 ห้ามช่วยกดหรือบอกทาง (บอกได้เฉพาะ "ลองทำตามที่คิดว่าใช่")
- [ ] ขอความยินยอมจากผู้ปกครอง/โรงเรียนเรื่องสังเกตการใช้งาน (มีผู้เยาว์ PLAN.md ข้อ 5 PDPA) ไม่ถ่ายหน้าคน

## หลังทดสอบ

1. รวมปัญหาเป็นตาราง: งาน · อาการ · ผู้ทดสอบที่เจอ (กี่คน) · ความรุนแรงสูงสุด · ภาพหน้าจอ (ถ้ามี ไม่มีหน้าคน)
2. ความรุนแรง 3–4 หรือเจอ ≥ 3 คน → เปิด issue ใน GitHub ให้แก้ก่อน go-live
3. ข้อความที่ไม่เข้าใจ → แก้ใน `apps/web/i18n/th.ts` (น้ำเสียงตาม `docs/design.md` ข้อ 7)
4. บันทึกผลสรุปท้ายไฟล์นี้ (วันที่ จำนวนผู้ทดสอบ อุปกรณ์ ปัญหาหลัก สิ่งที่แก้แล้ว)
