# สิทธิ์: บทบาท × ข้อมูล (เฟส 0)

บังคับที่ระดับ DB ด้วย RLS ผ่าน `app.current_user_id()` เท่านั้น ค่าเริ่มต้นปฏิเสธ

| ข้อมูล | นักเรียน (เจ้าของบริษัท) | ครู (ห้องตัวเอง) | ผู้ดูแลระบบ | ไม่ล็อกอิน |
|---|---|---|---|---|
| บริษัท / ผังบัญชี / งวด | อ่าน, แก้ชื่อ/ผังบัญชีของตัวเอง | อ่านอย่างเดียว | ไม่เห็น | ไม่เห็น |
| สมุดรายวัน / ยอดคงเหลือ | อ่าน, ลงผ่าน `post_journal()` เท่านั้น | อ่านอย่างเดียว | ไม่เห็น | ไม่เห็น |
| audit_log | ไม่เห็น | ไม่เห็น | อ่านเฉพาะโรงเรียนตัวเอง | ไม่เห็น |
| idempotency_keys / document_sequences | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ |
| credentials / sessions / login_attempts | ผ่านฟังก์ชันของตัวเองเท่านั้น (เปลี่ยนรหัส, ออกจากระบบ) | รีเซ็ตรหัส/เตะอุปกรณ์ เฉพาะนักเรียนในห้องตัวเอง | ยังไม่มี (รีเซ็ตรหัสครูผ่าน CLI `set-password`) | ล็อกอินผ่าน API เท่านั้น |
| teacher_alerts | ไม่เห็น | เห็นของตัวเอง | ไม่เห็น | ไม่เห็น |

- ไม่มีใคร UPDATE/DELETE สมุดรายวันและ audit_log ได้ (trigger บล็อก แม้เป็นเจ้าของตาราง)
- ผู้ดูแลระบบจัดการครู/ห้อง ไม่ได้ดูข้อมูลบัญชีของนักเรียน
- ตารางผู้ใช้/ห้อง/การลงทะเบียน: เขียนผ่านฟังก์ชันของเฟส 1 (ยังไม่เปิดให้ app_rw เขียนตรง)
