# สิทธิ์: บทบาท × ข้อมูล (เฟส 0)

บังคับที่ระดับ DB ด้วย RLS ผ่าน `app.current_user_id()` เท่านั้น ค่าเริ่มต้นปฏิเสธ

| ข้อมูล | นักเรียน (เจ้าของบริษัท) | ครู (ห้องตัวเอง) | ผู้ดูแลระบบ | ไม่ล็อกอิน |
|---|---|---|---|---|
| บริษัท / ผังบัญชี / งวด | อ่าน, แก้ชื่อ/ผังบัญชีของตัวเอง | อ่านอย่างเดียว | ไม่เห็น | ไม่เห็น |
| สมุดรายวัน / ยอดคงเหลือ | อ่าน, ลงผ่าน `post_journal()` เท่านั้น | อ่านอย่างเดียว | ไม่เห็น | ไม่เห็น |
| audit_log | ไม่เห็น | ไม่เห็น | อ่านเฉพาะโรงเรียนตัวเอง | ไม่เห็น |
| idempotency_keys / document_sequences | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ | ไม่มีสิทธิ์ |
| credentials / sessions / login_attempts | ผ่านฟังก์ชันของตัวเองเท่านั้น (เปลี่ยนรหัส, ออกจากระบบ) | รีเซ็ตรหัส/เตะอุปกรณ์ เฉพาะนักเรียนในห้องตัวเอง | รีเซ็ตรหัส/ปิดบัญชี ทุกคนในโรงเรียนตัวเอง (ปิดตัวเองไม่ได้) | ล็อกอินผ่าน API เท่านั้น |
| ผู้ใช้ / ห้อง / การลงทะเบียน | เห็นตัวเองและห้องที่เรียน | เห็นห้องตัวเองและนักเรียนในห้อง; นำเข้านักเรียนจาก CSV เข้าห้องตัวเอง | สร้างครู/ผู้ดูแล, สร้างห้อง, กำหนดครู, นำเข้านักเรียนเข้าห้องใดก็ได้ ในโรงเรียนตัวเอง | ไม่เห็น |
| teacher_alerts | ไม่เห็น | เห็นของตัวเอง | ไม่เห็น | ไม่เห็น |
| presence (ร่าง/หน้าที่เปิด) | เขียนของตัวเองผ่านฟังก์ชัน | อ่านเฉพาะห้องตัวเอง | ไม่เห็น | ไม่เห็น |
| spectate_log | เห็นแค่ชื่อครูที่กำลังดูตัวเอง (`app.my_watchers()`) | เริ่ม/หยุดดูสดเฉพาะนักเรียนในห้องตัวเอง (ทุกครั้งถูกบันทึก) | ไม่เห็น (เฟสถัดไป: รายงานการเข้าดู) | ไม่เห็น |
| ช่อง realtime | ฟังได้ `student:<ตัวเอง>` และ `company:<บริษัทตัวเอง>` | ฟังได้ `company:<บริษัทนักเรียนในห้อง>` | — | ไม่ได้ |
| submissions / submission_events | เห็นของตัวเอง; ส่งตรวจได้เมื่อเป็นร่าง/ถูกส่งกลับ | เห็นและเปลี่ยนสถานะ (เริ่มตรวจ/ส่งกลับ/ให้ผ่าน/ปิด) เฉพาะห้องตัวเอง; การเปิดดูถูกบันทึก | ไม่เห็น | ไม่เห็น |

- ไม่มีใคร UPDATE/DELETE สมุดรายวัน, audit_log และ submission_events ได้ (trigger บล็อก แม้เป็นเจ้าของตาราง)
- บริษัทที่ส่งตรวจแล้วถูกล็อกที่ DB (trigger) จนกว่าครูส่งกลับ
- ผู้ดูแลระบบจัดการครู/ห้อง ไม่ได้ดูข้อมูลบัญชีของนักเรียน
- ตารางผู้ใช้/ห้อง/การลงทะเบียน: เขียนผ่านฟังก์ชัน security definer เท่านั้น (app_rw เขียนตรงไม่ได้)
- นำเข้า CSV เก็บแค่รหัสนักเรียน ชื่อ และห้อง (PDPA) คอลัมน์อื่นในไฟล์ไม่ถูกส่งออกจากเบราว์เซอร์
