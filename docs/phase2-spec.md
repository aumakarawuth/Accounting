# เฟส 2 — ขาย ซื้อ ลูกหนี้ เจ้าหนี้ ภาษีมูลค่าเพิ่ม ภาษีหัก ณ ที่จ่าย (สเปก)

สถานะ (7 ต.ค. 2569): เจ้าของโปรเจกต์ยืนยันแล้ว **T4** (tax point บริการตามกฎหมาย) · **T5** (หัก ณ ที่จ่ายอัตรามาตรฐาน + ใส่เอง)
· **T7** (จด VAT เป็นค่าเริ่มต้น ปรับได้) · **T11** (เลขที่ `IV-0001` ต่อเนื่อง) หัวข้ออื่นทำตามร่างจนกว่าจะแจ้งเปลี่ยน
(บันทึกใน `docs/assumptions.md` ข้อ 25)

ลำดับ: เจ้าของโปรเจกต์เลือกทำเฟส 2 ก่อนเฟสกลาง (self-host) เมื่อ 7 ต.ค. 2569 ต่างจากลำดับใน PLAN.md ข้อ 12
เฟสกลางยังต้องทำก่อน go-live

## 2. หลักการที่ไม่เปลี่ยนจากเฟส 1

- เอกสารทุกใบลงบัญชีผ่าน `acc.post_journal()` เท่านั้น (ดุลแน่นอน, idempotency, เลขที่ไม่ข้าม, ปิดงวด, ล็อกตอนส่งงาน)
- ผ่านแล้วแก้/ลบไม่ได้ ยกเลิก = ทำเครื่องหมายยกเลิก + กลับรายการ (ใบกำกับภาษีที่ยกเลิกยังเก็บไว้ตามกฎหมาย)
- คำนวณภาษีที่ฐานข้อมูลที่เดียว (ฟังก์ชัน SQL) หน้าจอแสดงตัวอย่างด้วยสูตรเดียวกัน และมีเทสต์ชุดเดียวกันทั้งสองฝั่ง
- เงินเป็นสตางค์ (BigInt ฝั่งเว็บ, `numeric(18,2)` ฝั่ง DB) ไม่ใช้ float
- ร่างเอกสารเก็บในเครื่อง (IndexedDB) แบบเดียวกับสมุดรายวัน ครูดูสดได้
- สิทธิ์: นักเรียนเจ้าของบริษัทเขียน ครูประจำห้องอ่าน/คอมเมนต์ (RLS เดิม)

## 3. กติกาภาษี (ต้องยืนยัน)

| # | เรื่อง | ร่างที่จะทำ |
|---|---|---|
| T1 | อัตรา VAT | 7% เก็บอัตราในเอกสารทุกใบ ค่าเริ่มต้นตั้งที่บริษัท (เปลี่ยนได้ถ้าอัตราตามกฎหมายเปลี่ยน) |
| T2 | ราคารวม/ไม่รวม VAT | เลือกต่อเอกสาร: แยก VAT (ภาษี = ฐาน × 7%) หรือรวม VAT (ภาษี = รวม × 7/107) |
| T3 | การปัดเศษ | คิดภาษีจากยอดรวมทั้งใบ (หลังหักส่วนลด) ปัดครึ่งขึ้นที่สตางค์ ไม่คิดรายบรรทัด |
| T4 | จุดความรับผิด (tax point) | **สินค้า**: วันที่ออกใบกำกับ/ส่งมอบ → ภาษีขาย/ภาษีซื้อทันที · **บริการ**: เมื่อรับ/จ่ายเงิน → ขายเชื่อลง "ภาษีขายยังไม่ถึงกำหนด" แล้วโอนเป็นภาษีขายตามสัดส่วนเงินที่รับ ฝั่งซื้อเหมือนกัน |
| T5 | หัก ณ ที่จ่าย | อัตรามาตรฐาน: ขนส่ง 1% · โฆษณา 2% · บริการ/รับจ้าง/วิชาชีพ 3% · ค่าเช่า 5% (เลือกจากรายการ หรือใส่อัตราเอง) ฐาน = ยอดก่อน VAT · เตือนเมื่อยอดต่อครั้งต่ำกว่า 1,000 บาท (ไม่บังคับ) |
| T6 | ภาษีซื้อ | ขอคืนในเดือนของวันที่ในใบกำกับเท่านั้น (ยังไม่สอนการใช้สิทธิ์ย้อนหลัง 6 เดือน) |
| T7 | บริษัทไม่จด VAT | ตั้งที่บริษัท ออกใบกำกับภาษีไม่ได้ (ออกได้แค่ใบแจ้งหนี้/ใบเสร็จ) VAT ที่จ่ายตอนซื้อรวมเป็นต้นทุน |
| T8 | ใบลด/เพิ่มหนี้ | ต้องอ้างใบกำกับเดิม ใส่เหตุผล ลดได้ไม่เกินยอดเดิม คิดภาษีตามส่วนต่าง |
| T9 | ข้อมูลบนใบกำกับ (ม.86/4) | คำว่า "ใบกำกับภาษี" · ชื่อ ที่อยู่ เลขผู้เสียภาษี + สำนักงานใหญ่/สาขาของผู้ขาย · ชื่อ ที่อยู่ของผู้ซื้อ (ผู้ซื้อจด VAT ต้องมีเลขผู้เสียภาษี + สาขา) · เลขที่ วันที่ · รายการ จำนวน มูลค่า · ภาษีแยกจากมูลค่า · ตรวจเลขผู้เสียภาษี 13 หลักด้วยหลักตรวจสอบ |
| T10 | ปิดภาษีประจำเดือน | รายการปิด: เดบิตภาษีขาย เครดิตภาษีซื้อ ผลต่าง → ภาษีมูลค่าเพิ่มที่ต้องชำระ (2220) หรือ ภาษีมูลค่าเพิ่มรอขอคืน (ใหม่) |
| T11 | เลขที่เอกสาร | แยกชุดต่อประเภท ต่อเนื่องไม่รีเซ็ต เหมือนสมุดรายวัน: `IV-0001` ขายเชื่อ · `CS-` ขายสด · `RE-` รับชำระ · `CN-` ลดหนี้ · `DN-` เพิ่มหนี้ · `PI-` ซื้อ · `PV-` จ่ายชำระ · `WT-` 50 ทวิ |

## 6. โครงข้อมูล (ร่าง)

- `acc.companies` เพิ่ม: เลขผู้เสียภาษี, สาขา (`00000` = สำนักงานใหญ่), ที่อยู่, จด VAT หรือไม่, อัตรา VAT เริ่มต้น
- `acc.parties` ลูกค้า/ผู้ขาย: รหัส ชื่อ เลขผู้เสียภาษี สาขา ที่อยู่ จด VAT เครดิต (วัน) ประเภทหัก ณ ที่จ่ายเริ่มต้น
- `acc.items` สินค้า/บริการ: รหัส ชื่อ หน่วย ราคา บัญชีรายได้/ค่าใช้จ่าย เป็นบริการ (กำหนด tax point)
- `acc.documents` + `acc.document_lines`: ประเภท เลขที่ วันที่ คู่ค้า (เก็บสำเนาชื่อ/ที่อยู่/เลขภาษี ณ วันออก) แบบราคา อัตรา ยอดก่อนภาษี ภาษี รวม หัก ณ ที่จ่าย ครบกำหนด อ้างเอกสารเดิม รายการบัญชีที่สร้าง ยกเลิกเมื่อ/เหตุผล
- `acc.allocations`: รับ/จ่ายชำระตัดเอกสารไหนเท่าไร (ยอดค้าง = รวม − ตัดแล้ว − ลดหนี้)
- `acc.wht_certificates`: 50 ทวิ ผูกกับการจ่ายชำระ
- ฟังก์ชัน SQL: `post_sales_invoice`, `post_receipt`, `post_credit_note`, `post_purchase`, `post_payment`, `void_document`, `close_vat_month` ทุกตัวเรียก `post_journal` และล็อกเอกสารที่ตัดชำระ (`for update`) กันตัดเกินเมื่อกดพร้อมกัน

## 7. เทสต์ความถูกต้อง (เขียนก่อนโค้ด)

- สูตรภาษี: สุ่ม 10,000 ชุด (แยก/รวม VAT ส่วนลด จำนวนทศนิยม) เทียบกับคำนวณอ้างอิง ทั้ง SQL และ TypeScript ต้องได้ตรงกันทุกสตางค์
- ยอดคุมลูกหนี้/เจ้าหนี้ (1210/2110) = ผลรวมยอดค้างรายเอกสารเสมอ หลังลำดับเอกสารสุ่ม (ขาย รับบางส่วน ลดหนี้ ยกเลิก)
- รับชำระพร้อมกันหลายคำขอตัดใบเดียวกัน ไม่เกินยอดค้าง · ลดหนี้ไม่เกินยอดเดิม
- เลขที่ต่อประเภทไม่ข้าม/ไม่ซ้ำเมื่อออกพร้อมกัน · ใบกำกับที่ผ่านแล้วแก้ไม่ได้
- tax point บริการ: ภาษีขายยังไม่ถึงกำหนดเหลือ 0 เมื่อรับครบ · รายงานภาษีขายรวมเฉพาะที่ถึงกำหนด
- ภ.พ.30: ภาษีขาย − ภาษีซื้อ = ยอดในรายการปิด · หลังปิด 2210/1410 ของเดือนเป็นศูนย์
- RLS: นักเรียนคนอื่นอ่านเอกสาร/คู่ค้าไม่ได้ · ส่งงานแล้วออกเอกสารไม่ได้

## 9. ลำดับงานย่อย

1. **2.1 ข้อมูลหลัก**: โปรไฟล์ภาษีบริษัท ลูกค้า/ผู้ขาย สินค้า/บริการ ผังบัญชีเพิ่ม
2. **2.2 ขาย**: ขายเชื่อ/ขายสด รับชำระ ลดหนี้/เพิ่มหนี้ ยกเลิก อายุลูกหนี้
3. **2.3 ซื้อ**: ซื้อเชื่อ/ซื้อสด จ่ายชำระ 50 ทวิ อายุเจ้าหนี้
4. **2.4 ภาษี**: รายงานภาษีขาย/ซื้อ ภ.พ.30 + ปิดภาษีเดือน รายงานหัก ณ ที่จ่าย
5. ทดสอบโหลด k6 ซ้ำ (เพิ่มรูปแบบออกใบกำกับ/รับชำระ)

## 10. สถานะและสิ่งที่เลื่อนไป

- **2.2 ขาย เสร็จ**: ฟอร์มเอกสารขาย (มือถือ 4 ขั้น / iPad-คอม ฟอร์ม + กระดาษตัวอย่างข้างกัน) ใบที่ผ่านรายการพร้อมตราประทับและพิมพ์ได้
  รับชำระพร้อมหัก ณ ที่จ่าย (ระบบเสนอจากมูลค่าก่อน VAT) ใบลด/เพิ่มหนี้จากหน้าเอกสาร ยกเลิกพร้อมเหตุผล (RV) ลูกหนี้คงค้างตามอายุหนี้
- **เลื่อนไป** (ข้อ 2 สัญญาไว้ ยังไม่ทำในเอกสารขาย): ร่างเอกสารขายเก็บในเครื่อง (IndexedDB) และครูดูร่างเอกสารขายสด
  ตอนนี้มีเฉพาะสมุดรายวัน · ออกจากฟอร์มก่อนผ่านรายการ = ร่างหาย · จะทำพร้อม 2.3 ให้ใช้ร่วมกันทั้งขายและซื้อ
